# 发布说明

每次发布前在此文件新增一节，标题就是 `mygo.json` 的 `version`，例如 `## 0.2.0`。
`mygo build` 会把它渲染成自动更新窗口里的发布说明（由 `mygo.json` 的 `updates.changelog` 指向本文件）。历史变更与验证证据仍记录在 [CHANGELOG.md](CHANGELOG.md)。

## 0.2.1

- 修复“居中打印”不生效：`scale_mode: "actual"` 配合 `center: true`（默认）现在按 **1:1 为上限**居中打印——面单/页面比纸张小时保持原尺寸并居中，只有放不下时才缩小，绝不放大；需要 1:1 且从纸张左上角开始时传 `"center": false`。
- 业务对接参考客户端（文档第 7 节）的 `print`/`printBatch` 现在会透传 `scale_mode`/`direction`/`center`，照抄客户端即可使用页面适配字段。
- 更新配置与 0.2.0 相同，无需重新设置；从 0.2.0 升级会走增量下载。

## 0.2.0

- 新增应用图标：可执行文件、安装包、窗口标题栏、任务栏与托盘使用同一套青绿打印机图标。
- 界面语言默认简体中文；仍可在“设置”页切换为 English，已有配置中保存过的选择不会被覆盖。
- 新增检查更新：启动后自动检查（每天一次），也可从托盘菜单或“关于”页手动检查。新版本经签名校验并支持增量下载，确认后可在下次启动或重启时生效。
- 修复“关于”页在正式构建中把版本显示为 `dev` 的问题。
